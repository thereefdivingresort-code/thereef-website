# 英文版進度（/en/）

## 做法（11/24 Ambre：外國客人自己上網訂；翻譯由 Claude 直接寫；條款不用等業主）
- 網址：中文 `/courses/` ↔ 英文 `/en/courses/`；頁首「中｜EN」可以切換到同一頁的另一個語言（目前語言粗體）。
- 版面：英文頁跟中文頁用**同一套** Canva 座標與手機版設定（canvas-page.njk、mobile.json），只換文字。
- 翻譯檔：`src/_data/en/<頁>.json`
  - `t`：資料檔路徑 → [中文原文, 英文]。**中文改了、英文沒跟著改，`npm test` 會失敗並列出是哪一句**。
  - `style`：英文比較長的地方個別調整（鍵＝元素 id 或路徑；`fs` 字級倍數、`w` 寬度、`dx`／`dy` 位移）。
- 程式：`scripts/i18n.js`（換文字、站內連結自動加 /en）；公司資訊英文句子在 canvas-page.njk 的 `siteEn`；英文地址在 `site.json` 的 `en`。
- 預訂頁：英文表單 `src/_includes/booking-flow-en.njk`（結構跟中文版一樣，中文版改結構時兩份都要改）；JS 文字在 `booking.js` 的 `t(中文, 英文)`；品項英文名 `src/_data/en/prices.json`（價格數字仍只讀 prices.json）。
- 檢查：`scripts/verify-en.js`（加進 npm test）：翻譯對得上、品項都有英文名、英文頁沒有漏翻的中文。
