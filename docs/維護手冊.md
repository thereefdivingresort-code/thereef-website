# 綠芙網站｜維護手冊（給 Ambre 和業主）

> 後台還沒做之前，**最簡單的方法：跟 Claude 說要改什麼**，例如「把雙人房改成 2,600」。下面是 Claude 或工程師會改的地方，讓你知道東西放在哪。

| 我想改… | 改哪個檔 | 備註 |
|---|---|---|
| 電話、信箱、LINE、地址、統編 | `src/_data/site.json` | 全站頁首頁尾一起變 |
| 任何價格 | `src/_data/prices.json` | 預訂頁、課程頁、住宿頁、行程頁一起變 |
| 某一頁的文字 | `src/pages/頁名.njk` | 每段文字都在 blocks 裡 |
| 顏色、字的大小 | `src/assets/css/style.css` 最上面 | |
| 換照片 | `src/assets/img/` 放新圖，用一樣的檔名覆蓋 | |

改完後，網站會在幾分鐘內自動更新。

## 之後（第 3 階段）
會加一個網頁後台：登入後用表單改文字、換照片、改價格，不用碰這些檔案。
