## 做法（為什麼跟其他頁不一樣）
- Canva 原檔 DAHao-HiYfI 第 8 頁（UI v4｜預訂第 1 步：選購（七區塊），頁面 ID PBJYHQS7HXpXx05m，1440×2760）→ copy-design 成工作檔，原檔沒動
- 元素座標存在 `docs/booking-canva-elements.json`（只讀一次整頁；頁面備註是空的）
- **這頁是互動表單，選項目時列數會變（④–⑦ 勾一項多一列），卡片高度不能固定**，所以不用「整頁去字底圖＋座標」：
  - 頁首、頁尾：照 canvas-page 版型（`canvas_pages` 的做法），用首頁 home.json 的元素；頁首底圖＝關於頁同一段（白底 logo、潛水員、太陽），頁尾底圖＝關於頁頁尾
  - 中間：`src/_includes/booking-flow.njk`＋`src/assets/css/booking.css`，一般網頁排版，但每個尺寸照 Canva（卡片 x 154 寬 720、圓角 20、間隔 24；列高 48、間隔 14；品項框 300、數量框 130／120、小計 80；右側摘要 x 906、380×620，跟著捲動）
  - Canva 上的圖只有「開始訂製」上面的橘色雙箭頭 → 工作檔只留它、透明匯出 → `src/assets/img/booking/booking_chevron.webp`；卡片、框線、底色用網頁畫（顏色照 Canva：#f5f3ee 底、#d9d2c3 框、#12355b 字、#7a6a55 說明字、#ec6b0c 按鈕）
  - 版型改動：`canvas-page.njk` 加 `cv.flow`（中間一般排版的內容）、`cv.after`（接在後面的頁尾段）、`cv.css`、`cv.scripts`；只有預訂頁有這些設定。首頁、課程、住宿、行程、關於重建後截圖逐像素相同
- 換算：Canva x 原樣；Canva y ＋100 ＝ 網頁 y（上面多了 136px 共用頁首，Canva 頂端 36px 是空白）
- 全站規則：字級 ×0.9（框的位置、大小不變）；頁首選單沒有「聯絡」；價格全部讀 prices.json
- 算錢：只用 `src/assets/js/pricing.js`（網站和 npm test 共用）；`booking.js` 只負責「畫面選了什麼 → 哪些品項、幾份」
- 第 2–4 步（填資料、確認條款、付款）功能沒變，外觀改成同一套卡片；「前往付款」維持送審版（PAYMENT_LIVE = false）

- **四人房加床多一列**：Canva 四人房那列只有「間、晚」。網站選了豪華四人房會多一列「四人房加床（第 5、6 位）400／人・晚」，填人數（每間最多 2 位），晚數跟四人房同一個。要保留這列，還是改成別的方式（例如四人房那列變三個數量框）？

- **第 2–4 步**：Canva 上已沒有這幾頁，網站照第 1 步同一套卡片風格做（第 2 步填資料、第 3 步四個勾選、第 4 步前往付款＋付款完成範例＋付款方式／改期／查詢訂單）。要不要再請妳在 Canva 畫一版？
