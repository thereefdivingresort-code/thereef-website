# 手機版進度（分支 `mobile`，還沒合併 main、還沒上線）

## 做法（11/19 Ambre 定案：「看起來一樣，只是排法變直」）
- 只在螢幕寬 ≤ 768px 換排法；電腦版（1440、1280）跟改之前逐像素相同（回到頂部那一條除外）。
- 一套共用規則，九頁一起套用：
  - `src/assets/css/canvas-mobile.css`：手機版樣式（canvas-page.njk 用 `media="(max-width: 768px)"` 載入，電腦版不讀）
  - `scripts/mobile-blocks.js`：把每段的元素分組、排順序、做「插圖窗」（Eleventy 濾鏡 `mBlocks`）
  - `src/_data/mobile.json`：每頁每段的少量設定（哪些字排一組、哪塊插圖要切出來、底圖焦點）；頁首、頁尾全站一份
  - 電腦版不受影響的原理：分組外框 `.hc-mg` 在電腦版是 `display: contents`；插圖窗、手機 logo、☰ 按鈕電腦版 `display: none`
- 手機頁首：logo＋預訂＋☰（點開往下展開選單）；回到頂部改到右下角、捲動後才出現。
- 插圖窗：底圖＋魚的一塊等比縮到手機寬，魚一樣有進場與漂浮（漂浮幅度縮小）。有魚的插圖窗不帶底圖（避免接縫）。
- `join: true`：電腦版為了排版手動換的行，手機上接起來（電腦版畫面不變）。
