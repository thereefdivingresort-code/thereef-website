# 手機版進度（11/23 起，分支 `mobile`，還沒上線、沒合併 main）

## 做法（一套規則九頁共用）
- 手機寬（≤ 768px）才換排法；電腦版同一份 HTML，外框在電腦版都是 `display: contents`，所以 1440／1280 逐像素不變（回到頂部那塊除外）。
- 排法：`scripts/mobile-plan.js`（Eleventy filter `mplan`）把每段元素排成由上往下；同高的並排成一列；底圖上的照片／地圖／山海插畫用「pic」原樣切出來放滿手機寬；卡片用「box」以 CSS 畫。
- 每頁每段少量設定：`src/_data/mobile.js`（說明寫在檔案開頭）。外觀：`src/assets/css/canvas-page.css` 最後的 `@media (max-width: 768px)` 段。
- 插圖可以設 `at`（跟著某段文字），手機上放在那段文字旁，進場＋漂浮動畫照舊（幅度較小）。
- 頁首：logo＋預訂鈕一列、選單一列；頁尾：水墨山海切一塊＋深藍底；回到頂部在手機改成右下角小圓鈕。

## 指令
- 建置：`npx eleventy`
- 截圖：`NODE_PATH=$(npm root -g) node scripts/mobile-shot.js <資料夾> desk|mobile|mobile2 [頁…]`（頁＝home courses stay trips about booking terms privacy refund）
- 電腦版逐像素比對：改前改後各截一次 desk，用 PIL `ImageChops.difference` 看 bbox（None＝完全相同）
- 比對圖：`python3 scripts/mobile-compare.py <資料夾> <頁> docs/compare/mobile/<頁>_compare.jpg`
